## 2026-10-14：按用户偏好重写 Prompt

- 入口标题缩短为“Prompt”。数学公式按用户后续更正采用单美元符号 `$...$`，不用双美元符号或反斜杠括号。
- 模板要求短代码、状态更新和主逻辑集中在单行，保留完整程序与 Markdown 围栏所需的语法换行；中文与英文、数字之间不留空格，代码、公式、字符串及 URL 保持正确。
- 题解必须包含“从样例和小数据出发”及“标准推导”：前者逐步跟踪输入和相关变量的操作前后状态，通过手算、朴素枚举、反例与扩大规模得到算法；后者给出严谨的常规推导与证明。允许两条路线导向同一算法，不虚称不同算法。
- 前置知识采用简短链接列表，无真实路径时标记待补；额外题目介绍后附可确认的原题链接。
- 使用本地 `stop-slop-zh` 技能，将适用于算法题解的去空话、去套路、具体动作与证据边界规则写入模板。未整体复制与题解无关的场景说明。
- 本轮（2026-10-14）实际验证：前端构建通过；Playwright 核验检查页标题与默认模板内容更新。未重复执行 DOM/Rust 套件，未调用外部 AI 评价实际输出；已有笔记中的自定义 Prompt 保留原文。
