# ACM-OS v0.1.1

本次更新改进学习月历与个人题解阅读，面向 Windows x64。

## 学习月历

- 首次主动加入题库即记为入库当天做过的题，支持单题导入和从比赛中选题入库，无需先标记学会。
- 日期格显示当天做题数，点击日期查看具体题目，通过“查看题解”进入题目详情与个人笔记。
- 同一天同一道题的入库、学习完成、复习完成合并为一道，保留活动说明与复习判定；同题不同日期分别计数。
- 按本地日期归属，重复导入不新增做题日期。缺少可靠主动入库时间的旧版迁移记录不补记。
- 保留当前下一次复习安排，逾期复习汇总到今天；不改变学习状态或生成额外计划。

## 个人题解与 Prompt

- 按 Obsidian Markdown 的原文章节顺序阅读，完整展示大致题意；前置知识、Hints、题解和额外题目等默认折叠。
- “题解”章节下的方法名采用加粗强调色文字，点击独立弹窗阅读正文，支持公式、代码和表格。
- 增加刷新笔记入口；弹窗支持 Escape、键盘焦点循环和关闭后焦点恢复。
- 上方“个人 Markdown”区域提供 Prompt，创建笔记前即可复制。已有笔记的自定义 `Prompt` / `提示词` 章节优先使用。
- 默认模板包含从样例逐步跟踪变量、从小数据扩大规模、标准推导、前置知识链接和额外题目要求。
- Prompt 仅用于展示与复制，没有内置模型调用或自动写回；在外部 AI 中使用后，请检查内容并保存到 Obsidian。

## 下载与更新

- `ACM-OS_0.1.1_x64-setup.exe`：Windows x64 安装包。
- `ACM-OS_0.1.1_windows-x64_portable.zip`：免安装版，解压后运行 `acm-os.exe`。
- `SHA256SUMS.txt`：下载附件的 SHA-256 校验值。

更新前退出旧程序，并备份工作区数据库与个人 Markdown。新版沿用现有工作区，数据库结构版本仍为 36。程序依赖 Microsoft Edge WebView2 Runtime，安装包尚未进行 Windows 代码签名。

完整产品流程及 Obsidian 配置见 [项目介绍](https://github.com/Mxiaocao/acm-os#readme)。
