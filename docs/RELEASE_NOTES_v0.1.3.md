# ACM-OS v0.1.3

本次为 Windows x64 小修复版本，包含两项使用体验改进。

## 修复内容

- 手动比赛保存成功后，清空比赛 ID、标题、日期与全部题面，恢复一张默认题号 A 的空白题目卡。保存失败时保留填写内容，方便重试。
- 题目详情的“打开原题”和比赛详情的“打开原比赛”改为调用系统默认浏览器，修复桌面应用中普通新窗口链接无响应的问题。启动浏览器失败时显示提示和可复制的网址，并支持重试。
- 原题地址支持有效的 HTTP/HTTPS 网页链接，兼容 Codeforces Gym 及手动录入的其他 OJ 来源；无来源的本地题目继续隐藏该入口。

## 下载与更新

- `ACM-OS_0.1.3_x64-setup.exe`：Windows x64 安装包。
- `ACM-OS_0.1.3_windows-x64_portable.zip`：免安装版，解压后运行 `acm-os.exe`。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。

更新前退出旧程序。新版沿用已有工作区，数据库结构仍为 38，从 v0.1.2 更新无需新的结构迁移。程序依赖 Microsoft Edge WebView2 Runtime，安装包尚未进行 Windows 代码签名。

浏览器启动与原站访问是两个环节。Codeforces 登录状态、Gym 比赛权限和网络条件仍可能影响题目访问，本次修复不绕过这些限制。

完整学习流程和 Obsidian 配置见 [项目介绍](https://github.com/Mxiaocao/acm-os#readme)。
