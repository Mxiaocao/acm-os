# ACM-OS v0.1.2

本次更新支持按实际日期补录做题，并公开发布现场／实时参赛与赛后 VP 记录功能，面向 Windows x64。

## 入库时填写实际做题日期

- 手动录入、Codeforces 单题导入、从比赛中选题入库时，均可填写“实际做题日期”，默认今天，补录可选过去的日期。
- 比赛同批新增题目共用所选日期，不同日期可分批加入。重复导入保留原记录，不把旧题改记到今天。
- 题目和做题日期一起保存，保存失败会整体回滚；首次导入时间仍表示实际导入时间。

## 月历补录与纠正

- 选中日期后可搜索题库题目并补录，已有首次做题记录也可直接修改日期。保存后跳转对应日期，重新计算月汇总。
- 修改会移动首次做题记录，原入库日不重复计数；同一天同一道题的入库、学习、复习活动仍只计一道。
- 学习完成和复习完成保留各自日期，复习安排、计划、奖励及个人 Markdown 不随做题日期修改。
- 旧版迁移题目可手动提供日期，软件不会根据迁移时间猜测历史。

## 现场比赛与赛后 VP

- 比赛详情可记录现场／实时参赛或赛后 VP，填写实际开始日期、时间和可选赛内 AC／总题数，支持修改和删除。
- 同一比赛可重复 VP，跨午夜按本地开始日期计一场。导入、收藏和补题不自动记为参赛。
- 月历分别显示现场、VP 场次和比赛详情，支持跳转比赛；比赛场次与做题数独立统计。
- 删除比赛后保留参赛标题与历史，不保留失效跳转。旧比赛不自动生成参赛记录。

## 下载与更新

- `ACM-OS_0.1.2_x64-setup.exe`：Windows x64 安装包。
- `ACM-OS_0.1.2_windows-x64_portable.zip`：免安装版，解压后运行 `acm-os.exe`。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。

更新前退出旧程序，备份工作区数据库与个人 Markdown。新版沿用现有工作区，通过正式启动流程将旧数据库迁移到结构版本 38，并生成迁移前数据库备份。新版本写入的数据库应继续使用新版本打开，勿直接交给不支持该结构的旧程序。数据库备份不包含 Markdown。程序依赖 Microsoft Edge WebView2 Runtime，安装包尚未进行 Windows 代码签名。

完整学习流程和 Obsidian 配置见 [项目介绍](https://github.com/Mxiaocao/acm-os#readme)。
