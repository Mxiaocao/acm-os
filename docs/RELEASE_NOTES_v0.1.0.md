# ACM-OS v0.1.0

首次 Windows 产品发布。

- 比赛书架根据窗口宽度计算每层容量，依次填满三层后再增加书架。
- 年份在各分类间共用，新建年份立即显示，已有年份可直接选用。
- 新增独立学习月历，查看过去的学习记录和下一次复习安排。
- 支持 Codeforces 单题链接导入和手动录入独立题目。
- 题库突出完整题号、标题、题面预览、难度及首次导入日期，支持关键词搜索。
- 题库预览渲染 LaTeX，摘要截断保留完整公式。
- 题面编辑框限制横向尺寸；调整题库导入入口、搜索栏和提示区域间距。
- 更新樱花粉界面及“未来知识代码之书”应用图标。

Windows x64 下载提供安装包、免安装 ZIP 和 SHA-256 校验文件。首次运行时按提示设置工作区。数据保存在本地，不随安装包分发。
